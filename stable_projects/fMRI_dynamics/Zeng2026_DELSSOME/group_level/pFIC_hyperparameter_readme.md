# pFIC hyperparameters
This document contains detailed explanations on each hyperparameter used for parameteric feedback inhibition control (pFIC) model. These hyperparameters, unlike model parameters such as wEE and wEI, are fixed and will not be optimized during the training process. Here, I broke down the hyperparameters into 3 categories:
  
1. [CAT1] Hyerparameters (e.g. effective external current) with values that are suitable for the vast majority of research questions. These hyperparameters can be treated as constants for almost all research questions unless you have a good reason to change them. 
2. [CAT2] Hyperparameters (e.g. min/max firing rate, searching range) with values that are suitable for some reaserch questions/datasets but their values could depend on the exact datasets you are working with. Thus, it is advisble to change them if something is not working for you.
3. [CAT3] Hyperparameters (e.g. TR, simulation period, FCD window size) with values that are dataset-specific. These hyperparameters **must be changed** according to specific datasets, otherwise, they will lead to inaccurate results and/or errors.


## List of hyperparameters
- `warmup`: **[CAT1]** warm-up period (in frames). This value refers to the number simulated frames required before the ODE solution stablizes (i.e., is past the initial transient phase). This short period can also be used to debug your codes on solving the ODEs before generating tens of minutes of simulated data. The warm-up frames will be eventually discarded from the final simulated time courses.
- `t_pre`: **[CAT3]** pre-simulation period (in minutes). This is the part to simluate the magnetic field stabilzation effect. *Most importantly*, the ratio of `t_pre` (when converted to seconds) and the time step size (`dt_training`, `dt_validation`, and `dt_test`, see below) must be an integer. Otherwise, it will lead to a downsampling error. The pre-simulation data will be eventually discarded from the final simulated time courses.
- `window_size`: **[CAT3]** window size used for generating FCD matrices. The window length is usually set to be 60 seconds divided by the TR of the dataset. For example, TR of HCP-YA is 0.72s, thus the window length is 60/0.72 = 83.
- `simulation_period`: **[CAT3]** total length of the simulation period (in minutes). For example, set this value to 14.4 when simulating HCP-YA fMRI run since each run lasts for 14.4 mins.
- `dt_training`: **[CAT3]** time step size used for solving the differential equations (in seconds) during training. A time step size is required to solve ODEs using [Euler integration](https://en.wikipedia.org/wiki/Euler_method). A small step size usually leads to more accurate solutions but takes substantially more time. Thus, for this acurracy-time tradeoff, we set the step size used during training to be relatively larger than validation and/or test sets. The idea is that we want to the training process to be faster, but the validation and testing more accurate. Note that the temporal resolution of the ODE solutions is much much higher than fMRI data (0.006s vs. 0.72s for HCP). In practice, the simulated fMRI time courses are implemented as a downsampled version of the simulated ODE time courses. As a result, the step size must be set carefully such that the length of simulated fMRI data (in seconds) must be an integer multiple of time step size (also in seconds). For example, setting the step size to be 0.006s is valid for a TR of 0.72s because 0.72/0.006 = 120 is an integer. In other words, simulated fMRI data downsamples the ODE solutions at every 120 time points.
- `dt_validation` & `dt_test`: **[CAT2]** time step size used for solving the differential equations (in seconds) during validation and test. These are similar to `dt_training`, but they may be set to be smaller.
- `TR`: **[CAT3]** Repetition time of the fMRI data.
- `wEI_a`, `wEI_b`, `wEI_c`, `wEI_d`: **[CAT2]** These 4 values define the searching range (i.e. upper & lower bounds) for model parameter wEI. Here, the level of inhibition, thus its searching range, scales with the mean functional connectivity (See [Rocchi et al.](https://www.nature.com/articles/s41467-022-28591-3), [Blanco-Hinojo et al.](https://www.liebertpub.com/doi/abs/10.1089/brain.2020.0844), [Beynel et al.](https://www.sciencedirect.com/science/article/pii/S1053811920300835#bib23)). Specifically, the upper bound, wEI_max, equals to wEI_a * FC mean + wEI_b; the lower bound, wEI_min, equals to wEI_c * FC mean + wEI_d. These values can be adjusted to adapt to different datasets.
- `use_tqdm`: **[CAT2]** Enable or disable the [tqdm module](https://tqdm.github.io/) during model training.
- `n_ROI`: **[CAT3]** Number of ROIs. For example, set it to 68 when using the Desikan parcellation.
- `classifier_save_path`, `predictor_save_path`: **[CAT3]** The path to the pretrained classifier and predictor models.
- `I0`, `gamma_kin`: **[CAT1]** constants for neural mass models. This `gamma_kin` is not to be confused with the `gamma_hemo` used in the hemodynamic model.
- `W_E`, `J_NMDA`, `a_E`, `b_E`, `d_E`, `tau_E`: **[CAT1]** more constants for the excitatory population. Detailed explanantions can be found in the supplementary (Section S8).
- `rE_min` & `rE_max`: **[CAT2]** the allowed minimum and maximum excitatory firing rate. Since the FIC model requires the excitatory firing rate to be maintained at around 3Hz. Thus a upper & lower bound are imposed to ensure that the excitatory firing rate is within a reasonable range during simluation. During optimization, if a set of parameters generate simulated data that are outside this range, the set of parameters will be discarded and not used for further optimization. If you think the pre-defined range (2.7Hz ~ 3.3Hz) is too strict, this range can be relaxed to (2.5Hz ~ 3.5Hz) or even further depending on the exact dataset you're using.
- `TE`: **[CAT3]** Echo time of the fMRI data.
- `B`: **[CAT3]** Magnetic field strength used by the fMRI protocol.
- `V0`, `kappa`, `gamma_hemo`, `tau`, `alpha`, `rho`, `r0`, `epsilon_hemo`: **[CAT1]** constants used for Balloon-Windkessel hemodynamic model.
